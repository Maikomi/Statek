# ⛵ Ship

A ship simulation project developed in **Unity**, featuring wind-driven movement, sail control, and basic water resistance.

### Features
- 🌬️ Wind-based propulsion and apparent wind simulation
- ⛵ Adjustable sail angle and opening
- 🌊 Basic hydrodynamic resistance and drift control

### Built With
- Unity
- C#
- Unity Input System

### Project Status
Work in progress — focused on improving sailing physics and ship handling.
